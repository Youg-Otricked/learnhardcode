Some HTML elements have meaning beyond whats visible. There are 4 elements, which all look the EXACT same as their b/u/i/s counterparts, but carry special meaning, and a search engine may use to find pages.

| Element  | Equivelent to | Why different?                                       |
| -------- | ------------- | ---------------------------------------------------- |
| `strong` | `b`           | Ment to draw attention to somthing                   |
| `em`     | `i`           | Ment to show emphasis                                |
| `del`    | `s`           | Ment to show text is deleted and replaced with `ins` |
| `ins`    | `u`           | Ment to show `del` text is replaced with this        |
