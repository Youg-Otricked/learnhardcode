Quantum C (C⁴) - More Powerful Than Explosives™

Quantum C Playground

Write Quantum C code and run it instantly in your browser!

Features:

  • Multi-return functions
  • Lambdas with fn syntax
  • F-strings: f"Hello {name}"
  • Type inference with auto
  • Default parameters
  • Destructure(@)

Quick Examples:

Hello World 
int main() {
    println("Hello, World!");
    return 0;
}
Lambda Example 
int main() {
    auto add = fn(int x, int y) {
        return x + y;
    };
    println(add(5, 3));
    return 0;
}
Multi-Return 
int, string get_user() {
    return 123, "Alice";
}

int main() {
    int id, string name = get_user();
    println(f"User: {name}, ID: {id}");
    return 0;
}
Arrays/Grids 
int main() {
    int x[] = [1, 2, 3];
    std::qout << x << '\n';
    int y[][] = [[@x][4, 5, 6][7, 8, 9]]std;
    std::qout << y << '\n';
    return 0;
}
Lists 
int main() {
    int[] z = [1, 2, 3];
    z.push(9);
    z.push([1, 2, 3]);
    int[] inner = [1, 89, 3434];
    z.push(inner);
    std::qout << z << '\n';
    inner.push(1234);
    std::qout << z << '\n';
    z.pop();
    z.pop();
    z.pop();
    std::qout << z << inner << '\n';
    return 0;
}

Syntax Guide:

  • Variables: int x = 5;
  • Functions: int add(int a, int b) { return a + b; }
  • Lambdas: auto f = fn(int x) { return x * 2; };
  • F-strings: string msg = f"Value: {x}";
  • Multi-return: int, string foo() { return 1, "hi"; }
